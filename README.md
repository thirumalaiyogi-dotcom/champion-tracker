# சாம்பியன் டிராக்கர் (Champion Mindset Tracker)

Champion Mindset தினசரி பழக்க டிராக்கர் — ஒரு தொடுதலில் டிக், வார/மாத ரிப்போர்ட், பழக்கவாரி streak, பழைய Excel டேட்டா ஏற்றுதல்.

- ஒரே `index.html` ஃபைல், சர்வர் தேவையில்லை
- போன் ஹோம் ஸ்கிரீனில் ஆப்பாக install செய்யலாம் (PWA), இணையம் இல்லாமலும் வேலை செய்யும்
- டேட்டா போனின் பிரவுசரில் மட்டும் சேமிக்கப்படும்
